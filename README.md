# 💰 Finanças PI

Aplicativo de controle financeiro desenvolvido como Projeto Integrador, utilizando React Native, Expo e TypeScript.

## 📖 Sobre o projeto

O Finanças PI foi criado para ajudar os usuários a organizar sua vida financeira de maneira prática e intuitiva. O aplicativo permite registrar receitas e despesas, categorizar movimentações, acompanhar o saldo e visualizar relatórios financeiros.

## ✨ Funcionalidades

- 👤 Cadastro e login de usuários
- 💵 Cadastro de receitas
- 💸 Cadastro de despesas
- 📂 Gerenciamento de categorias
- 📊 Relatórios financeiros
- 📄 Exportação de relatórios em PDF
- 💾 Armazenamento local dos dados

## 🛠 Tecnologias utilizadas

- TypeScript

## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/thavinear/Financas-PI.git
```

Entre na pasta do projeto:

```bash
cd Financas-PI
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npx expo start
```

Para executar na web:

```bash
npm run web
```
